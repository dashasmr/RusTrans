# RusTrans

Offline subtitle generator and translator (RU → FI / EN)

## Features

- Generate subtitles from video
- Translate Russian subtitles to Finnish and English
- Batch processing for TV series
- Works fully offline

## Screenshot

![App Screenshot](assets/screenshot.png)

## Tech Stack

- Python
- faster-whisper (speech recognition)
- Argos Translate (offline translation)
- CustomTkinter (GUI)
- ffmpeg
